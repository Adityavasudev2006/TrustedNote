# Included data

`aci-bench-corpus/`: original user-supplied dataset, unchanged.
`prepared/`: five normalized challenge splits plus manifest.json.

207 encounters: 67 training, 20 validation, three test sets of 40 each.
Only challenge_data conversation/note files are used in prepared splits.
Metadata and alternate transcripts are retained in the original corpus.
